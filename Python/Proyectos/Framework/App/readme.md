## Pasos para la instalación de Reflex
1. Crear la carpeta para el proyecto
2. Crear un entorno virtual para el proyecto
    ```sh
    python3 -m venv env
    ```
3. Activar el entorno virtual
    ```sh
    .\env\Scripts\activate
    ```
4. Instalar reflex
    ```sh
    pip install reflex
    pip install --upgrade pip --> si sale como sugerencia
    ```
5. Iniciar reflex
    ```sh
    reflex init
    ```
6. Correr el proyecto
    ```sh
    reflex run
    ```
## Como abrir el Proyecto
1. Montar el entorno virtual
    ```sh
    .\env\Scripts\activate
    ```
2. Iniciar reflex
    ```sh
    reflex run
    ```
